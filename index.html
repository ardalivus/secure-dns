Install

Pick your device.

The two versions solve the same problem in the simplest way each platform allows.

A Android 8.0+

Install the Android app.

Android does not let a normal app replace system DNS directly, so SecureDNS uses Android's VPN API to catch DNS requests locally.

Download APK
Looking for the latest release…
  1. Download the APK.
  2. Allow installation from your browser when Android asks.
  3. Open SecureDNS and tap Enable.
  4. Approve Android's VPN permission once.
About the VPN icon: Android shows it because the app uses VpnService. Your normal traffic is not sent through a remote VPN server.
i iPhone & iPad

Install the DNS profile.

iOS can apply encrypted DNS directly with a configuration profile, so there is no companion app and no VPN process.

Download profile
Signed profile · Cloudflare DNS over HTTPS
  1. Download the profile in Safari.
  2. Open Settings and install the downloaded profile.
  3. Confirm the profile named Secure DNS.
Why iOS may say “Unverified”: the profile is signed, but the signing certificate is self-signed rather than issued by a public certificate authority. You are not asked to install or trust a root certificate.

It does

  • Encrypt DNS lookups.
  • Avoid relying on the network's normal DNS resolver.
  • Keep web, voice, game and download traffic direct.
  • Use standard DNS-over-HTTPS providers.

It does not

  • Hide your public IP address.
  • Proxy all of your traffic.
  • Inspect or decrypt HTTPS content.
  • Fix blocks that happen beyond DNS, such as destination-IP blocking.
Privacy

Less collection is better.

No account

There is nothing to sign in to.

No ads

No advertising SDK is needed.

No analytics

The app does not need behavioral tracking to work.

No DNS history

SecureDNS is designed to forward lookups, not build a browsing history.

DNS requests are handled by the resolver you choose. The iOS profile currently uses Cloudflare. The Android app can use Cloudflare, Google Public DNS, or Quad9.

Remove

Nothing is permanent.

Android

Disable SecureDNS inside the app, then uninstall it normally if you no longer want it.

iPhone & iPad

Open Settings → General → VPN & Device Management, select the Secure DNS profile, then remove it.
